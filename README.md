# NATURALHEMP — Website

Website da NATURALHEMP (naturalhemp.pt) — bioconstrução com cânhamo e biomateriais, execução em obra.
Construído a partir do design Figma ("Sem título (Copy)").

## Páginas

| Ficheiro | Página Figma |
| --- | --- |
| `index.html` | OnePage |
| `servicos.html` | Serviços |
| `biomateriais.html` | Biomateriais |
| `parcerias.html` | Junta-te a nós — Parcerias |
| `faq.html` | FAQ |
| `natureza.html` | Natureza |

## Estrutura

- `assets/css/style.css` — estilos partilhados (cores e tipografia do Figma: Inter, Open Sans, Comforter Brush)
- `assets/js/main.js` — menu móvel, animações, carrossel, menus das categorias e formulários
- `assets/img/` — fotografias e marcas de água exportadas do Figma
- `assets/icons/` — ícones SVG exportados do Figma

Site estático, sem build: basta abrir `index.html` ou publicar a pasta (GitHub Pages).

## Notas

- Os formulários (contacto, parcerias, newsletter) abrem o cliente de email com a mensagem preenchida para `info@naturalhemp.pt`; não há servidor nem reCAPTCHA.
- Ligações Facebook e Google estão por preencher (`href="#"`).
- Os artigos do blog são os de exemplo do design.
